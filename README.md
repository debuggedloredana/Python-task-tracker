Python Task Tracker

A beginner Python project that allows users to manage their tasks through a simple command-line interface.


Features

1. Add tasks: Create new tasks and store them in a list.

2. View tasks: Display all tasks with their numbers and completion statuses.

3. Complete tasks: Mark existing tasks as completed.

4. Delete tasks: Remove tasks from the tracker

5. Data persistence: Save and load tasks using JSON.

6. Input validation: Handle invalid inputs and prevent errors.


Technologies Used

Python,
JSON,
File handling,
Visual Studio Code


What I Learned

Through this project, I developed my understanding of:

Functions and reusable code

Lists and dictionaries

Loops and conditional statements

Error handling using try/except

Reading and writing JSON files

List indexing and data manipulation


How to Run
1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:
python task_tracker.py
